# Умный глоссарий (`ru_ru`)

Умный глоссарий задаёт перевод **английского оригинала** до обращения к Google,
DeepL, KoboldCPP или OpenRouter. Первая версия работает только для русского языка.

## Чем отличаются файлы

- `glossaries/ru_ru/user.json` — ручные правила `English → Русский`;
- `glossaries/ru_ru/generated.json` — безопасные пары, автоматически найденные в
  существующих `en_us.json` и `ru_ru.json`;
- `dictionary.json` — исправления уже готового русского перевода;
- `cache.json` и `ai_cache.json` — переводы полных строк.

`user.json` создаётся пустым при первом включении функции. Пример находится в
`examples/glossary.user.example.json`.

## Формат правила

```json
{
  "source": "Mechanical Press",
  "target": "Механический пресс",
  "scope": ["create"],
  "apply": "phrase",
  "case_sensitive": false,
  "priority": 100,
  "note": "Термин мода Create"
}
```

- `scope`: namespace мода из `assets/<namespace>/lang/en_us.json`; `*` означает
  любую область;
- `apply: exact`: использовать правило только при совпадении всей строки;
- `apply: phrase`: защищать устойчивую фразу внутри более длинного текста;
- `apply: protect`: сохранять имя без перевода, в том числе внутри текста;
- `case_sensitive`: учитывать регистр;
- `priority`: приоритет среди правил одного файла.

Приоритет источников всегда такой: `user → generated → builtin`. Более
специфичный `scope` и `priority` разрешают конкуренцию внутри одного источника.

## Автоматический сбор

Перед переводом MineAI делает snapshot уже существующих пар локализаций и только
после этого запускает движок. Поэтому машинные результаты текущего запуска не
попадают в обучение.

Собираются только короткие пары по одинаковому JSON-ключу: от 1 до 5 слов, не
длиннее 80 символов, с кириллицей в переводе и без `%s`, NBT/Minecraft-тегов,
макросов или Markdown-ссылок. Автоматически найденные пары применяются только к
целой строке (`exact`): программа не предполагает, что готовый перевод фразы
безопасно вставлять в другой контекст. Книги, SNBT и произвольные предложения не
служат источником обучения в этой версии.

Регистр автоматически найденного английского источника не создаёт отдельное
правило: `None` и `NONE` объединяются, если перевод одинаковый. Если у
одинакового `source + scope` несколько переводов, в том числе после такой
нормализации, они записываются в `conflicts`, но ни один вариант не применяется
автоматически. Сам `generated.json` обновляется атомарно.

## Кэш

При включённом глоссарии его fingerprint добавляется в namespace ключа кэша.
После изменения `user.json` строка будет переведена заново. При выключенной
галке используются прежние ключи (`ru_Source text`) без изменений.

## Как поделиться глоссарием

1. Оставьте только проверенные и однозначные термины.
2. Укажите точный `scope` и пояснение в `note`.
3. Проверьте JSON.
4. Создавайте отдельный PR на один мод или одну тематическую группу.

Не публикуйте личные пути, токены и непроверенные машинные переводы.
