# Окно выбора содержимого для перевода

После анализа основное окно показывает только компактную сводку выбранных элементов и кнопку «Настроить выбор…». Полная выборка открывается в отдельном модальном окне, чтобы длинный список не вытеснял статус задачи и журнал. В диалоге используется дерево: верхний уровень содержит мод, книгу или квестовый файл, а дочерний — главы и технические части большого FTB-файла. Доступны поиск, фильтр типа, массовое включение и снятие галочек, а также счётчик выбранных конечных элементов. Отмена не меняет текущий выбор; «Применить» сохраняет его до следующего анализа или смены папки сборки.

Монолитный `config/ftbquests/quests/lang/en_us.snbt` сопоставляется с файлами из `quests/chapters`. Все шестнадцатеричные ID главы, квестов, задач, наград и изображений получают единственного владельца. Название берётся из `chapter.<ID>.title`. Несопоставленные записи попадают в группу «Прочие записи». Группа больше 500 переводимых строк автоматически делится на устойчивые части. Если файлов глав нет, всё содержимое делится на технические части тем же способом. Индекс `ID → строки` строится за один проход по языковому файлу.

Выбранные группы передаются оценщику и SNBT-процессору как стабильные сегментные ключи. Процессор фильтрует извлечение и обратную подстановку по ID, поэтому одинаковый исходный текст в снятой главе не меняется. При существующем целевом `ru_ru.snbt` режим «Дополнить» обрабатывает только выбранные непереведённые записи и сохраняет остальные.

В дереве отключено обычное выделение строк: состояние перевода определяется только чекбоксом. Отмеченный чекбокс имеет бирюзовый цвет, наведение — нейтральный сине-серый фон и рамку. Для светлой темы используются отдельные контрастные оттенки.
