# Beta40: связанные словари локализации квестов

## Причина

FTB Quests может хранить в SNBT не видимый текст, а ссылку вида
`{atm9.quest.getting_started}`. Английское значение такой ссылки находится в
обычном Minecraft-словаре, например
`kubejs/assets/kubejs/lang/en_us.json`. До Beta40 выбор «только квесты» исключал
этот файл как интерфейс модов и ошибочно отправлял саму ссылку переводчику.

## Решение

Перед анализом и переводом строится план зависимостей квестов. Он извлекает
только точные ссылки из выбранных SNBT-узлов, ищет их сначала в распакованных
словарях сборки, затем — в словарях ресурс-паков и модов. Для каждого источника
создаётся минимальный набор реально используемых ключей. Русский JSON
записывается только в создаваемый resource pack; английские KubeJS-файлы и JAR
не изменяются.

Анализ, оценка количества строк и выполнение используют один план. Неразрешённые
ключи выводятся отдельным предупреждением. Ссылки, числовые части цветовых кодов
Minecraft, химические обозначения и служебная часть вложенного JSON не
передаются переводчику.

## Критерии проверки

- тестовый режим «только квесты» создаёт `assets/kubejs/lang/ru_ru.json`;
- в выход попадают только ключи, на которые ссылаются выбранные квесты;
- локальный ИИ и Google получают одинаковые чистые текстовые значения с типом
  промпта `quests`;
- исходный `kubejs/assets/kubejs/lang/en_us.json` остаётся байт-в-байт прежним;
- поиск FTB охватывает главы, таблицы наград и разбитый английский каталог без
  двойного учёта монолитного `en_us.snbt`.
