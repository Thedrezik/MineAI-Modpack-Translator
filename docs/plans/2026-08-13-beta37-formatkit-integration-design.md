# Beta37: объединение MineAI Translator и MineAI-FormatKit

## Граница ответственности

Beta37 остаётся самостоятельным приложением. Оно выбирает папку Minecraft,
сканирует JAR и loose-файлы, управляет UI, кэшем, пакетами, движками перевода и
выходными архивами. Встроенный `mineai_formatkit` получает только логический
путь и декодированный исходный текст, выделяет безопасные единицы перевода,
возвращает их в канонический английский skeleton и проверяет структуру.

## Совместимость

Новый SDK имеет приоритет для форматов, которые он уверенно распознаёт.
Проверенные адаптеры Beta36 остаются резервными: Modonomicon, Heracles, XML,
properties и другие форматы не теряют покрытие. Между двумя API используется
узкий bridge, возвращающий прежний контракт `TranslationPlan`, поэтому движки,
кэширование и интерфейс приложения не зависят от внутреннего API SDK.

Для GuideME и IE сохраняются смысловые блоки Beta36. Bridge выполняет
синтетическую проверку покрытия: если SDK понимает все видимые span старого
плана, он становится вторым независимым валидатором итоговой реконструкции. Если
SDK считает переводимый Beta36-фрагмент защищённым (например alt-текст
изображения), используется цельный lossless-план Beta36 без смешивания двух
несовместимых моделей документа. Locale JSON, современный Patchouli и Oracle
Index обрабатываются точными span-единицами SDK. Реальные legacy-варианты,
которые SDK намеренно отклоняет, переходят на прежний парсер: это JSON с
конфликтующими дубликатами ключей и Patchouli со строковым массивом `pages`.

Существующий целевой перевод не становится источником структуры. Bridge
сопоставляет его единицы с планом английского оригинала, проверяет защищённые
фрагменты и переиспользует только безопасный целевой payload. Повреждённый или
несовместимый target отбрасывается, после чего документ снова собирается из
английского skeleton.

## Выход и проверка

Проект расположен отдельно от Beta36. В EXE включаются оба пакета:
`mineai_formatkit` как основной SDK и `formatkit` как слой совместимости.
Критерии готовности: тесты приложения и SDK, интеграционные тесты bridge,
побайтовый identity round-trip, synthetic apply, аудит реальных JAR и успешный
запуск собранного EXE.

Финальный read-only аудит 9 установленных Prism-сборок охватил 2 929 JAR,
2 250 файлов книг/руководств и 8 692 locale JSON. Проверены 24 071 единица книг,
25 197 locale-единиц и 1 226 перемещаемых зависимостей. Identity round-trip и
synthetic apply завершились без ошибок.

## Ограничение публикации

В исходном приватном репозитории MineAI-FormatKit на момент объединения нет
файла лицензии. Beta37 можно собирать и проверять локально в рамках выданного
доступа, но публикация объединённого исходного кода или бинарника требует
явной лицензии либо разрешения владельца FormatKit.
