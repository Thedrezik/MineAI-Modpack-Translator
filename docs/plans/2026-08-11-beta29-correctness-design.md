# Beta29: единая структурная модель документов

## Цель

Устранить шесть подтверждённых расхождений в Markdown, SNBT и JSON-книгах, исключить ложные ошибки на технических фрагментах и сохранять выбранные версию Minecraft, язык перевода и движок. Интерфейсы CustomTkinter и PyQt6 не перерабатываются.

## Общий AST

Все структурированные форматы представляются общей моделью документа: неизменяемый исходный скелет, список типизированных текстовых узлов, стабильный путь каждого узла и правила обратной сборки. Узел содержит исходный текст, существующий перевод, область/контекст, технические токены и признак переводимости. Анализатор, оценщик и процессор получают данные только из этой модели, поэтому не реализуют собственные несовпадающие фильтры.

Форматные адаптеры отвечают только за разбор и lossless-сборку:

- Markdown распознаёт YAML front matter только в начале документа, выделяет заголовки, абзацы и видимый текст, а ссылки, теги, цвета, экранирование и физические переносы оставляет в скелете.
- JSON использует типизированные обратимые пути. Строковые ключи и индексы списков не смешиваются; `/` внутри ключа безопасен.
- SNBT выделяет структурные слоты по идентификатору записи, имени поля и номеру повторения. BQ использует те же узлы поверх JSON-структуры.

Для SNBT актуальный исходный файл всегда остаётся структурной основой. Существующие переводы сопоставляются с исходными полями по стабильным идентификаторам извлечённых записей; отсутствующие в переводе поля добавляются из нового исходника и попадают в очередь. Анализатор разрешает целевой locale-файл и сравнивает его с исходным через ту же baseline-логику, что процессор и оценщик.

Для языков с общей латиницей оценщик SNBT и BetterQuesting использует baseline-aware выборку, совпадающую с реальной обработкой.

Существующие публичные функции выборки остаются тонкими совместимыми оболочками над AST, чтобы переход не менял внешние контракты процессоров за пределами Beta29.

## Классификация коротких значений

Обрывочные и технические значения вроде `'s` и `1x` не становятся переводимыми узлами, не отправляются ни локальному ИИ, ни Google и не увеличивают счётчик ошибок. Содержательные названия вроде `VoidShimmer Goo`, `Steam Age` и `Pocket Computer Addons` остаются переводимыми. Если движок возвращает такое название без изменений, действует существующая цепочка повтора и fallback.

## Состояние интерфейса

Qt-интерфейс записывает текущие значения версии Minecraft, целевого языка и движка в существующий `settings.ini` и восстанавливает их после запуска. Неизвестное или устаревшее значение безопасно заменяется текущим значением по умолчанию. CustomTkinter не изменяется.

## Проверка

Каждый дефект сначала воспроизводится отдельным падающим тестом. После исправления запускаются целевые тесты, полный набор unit-тестов, `compileall`, сборка PyInstaller и проверка запуска созданного Beta29 EXE.
